## 🌐 How to Host It Online in 60 Seconds (Free!)

### Method 1: Netlify Drop (Easiest & Fastest — No terminal needed)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this entire `23rd Project` folder onto the page.
3. Netlify will generate a live URL in 5 seconds (e.g. `shreya-23rd-birthday.netlify.app`)!

### Method 2: Vercel CLI
Open PowerShell in this folder and run:
```powershell
npx vercel
```
Follow the 3 prompts and your site is instantly live with a custom HTTPS link.

### Method 3: GitHub Pages
1. Create a free repo on GitHub (e.g. `shreya-23`).
2. Push this folder:
   ```powershell
   git init
   git add .
   git commit -m "Happy 23rd Birthday Shreya!"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USER>/shreya-23.git
   git push -u origin main
   ```
3. In GitHub repo **Settings -> Pages**, set Source to `main` branch, and it will be live at `https://<YOUR_USER>.github.io/shreya-23/`.
